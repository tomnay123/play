# CodingGame

A browser game that teaches coding to children aged 7–12. Players tap picture blocks to build a program, then press Go to steer a robot to the stars. Text-based coding is planned for later levels, once players have the basics.

## Levels and concepts

1. Get the star!: moving
2. Turn the corner: turning
3. Zig zag: planning a route
4. Staircase: Repeat loops
5. Around the pond: loops inside loops
6. The long road: Repeat until ⭐
7. Snail shell: If / otherwise (sensing a path ahead, left or right)
8. Hurdles: My block (making your own function)

Each level can unlock blocks and set a block limit, so the new idea is the way to solve it. A "New block!" card explains each idea the first time it appears.

## Run it

Open `index.html` in a browser. No build step or install needed.

## Files

- `index.html`: page layout
- `style.css`: styles
- `game.js`: levels, blocks, the program runner and the board drawing (add levels to `LEVELS`)
