# CodingGame

A browser game that teaches coding to children aged 7–12. Players tap picture blocks (forward, turn left, turn right, and later repeat loops) to build a program, then press Go to steer a robot to the star. Text-based coding is planned for later levels, once players have the basics.

## Run it

Open `index.html` in a browser. No build step or install needed.

## Files

- `index.html`: page layout
- `style.css`: styles
- `game.js`: levels, blocks, and the program runner (add levels to `LEVELS`)
